# 🔐 Gerador e Verificador de Senhas em Python

Um script simples desenvolvido em Python para ajudar você a criar senhas fortes e seguras de forma personalizada através do terminal.

## 🚀 Funcionalidades

- **Geração Personalizada:** Escolha exatamente quantos números, letras e caracteres especiais deseja na sua senha.
- **Validação de Entrada:** O programa valida se os valores inseridos pelo usuário são realmente numéricos, evitando erros de execução.
- **Embaralhamento Aleatório (`Shuffle`):** Mistura todos os caracteres gerados para garantir maior aleatoriedade e segurança da senha final.
